# Hold–Find–Plan prototype

Clinician-directed activity materials for practicing a hold-then-act sequence.
This is not a medical device and does not claim to treat ADHD, concussion, stroke, or any other condition.

## Live page

Open `index.html` in a browser, or enable GitHub Pages on this repo (Settings → Pages → Deploy from branch `main`).

## What to do in the room

1. Set n, encode, delay, and wrap on the page (clinic changes one of these at a time).
2. **Hybrid A:** roll or set physical picture cubes. Name them. Cover with a folder. The page times the delay and then shows a scene.
3. **Hybrid B:** the page flashes icons, then goes black. Search a printed photo card on the table.
4. Do only the assigned wrap. Log the trial. Home stays frozen at the last successful clinic level.

No accounts. No patient identifiers. Copy the log off the device if Nan wants it in the chart.

## Physical kit to sit next to this page

- 9 blank 16 mm dice + sticker icons (or picture cubes)
- File folder occluder
- Phone timer as backup
- Optional printed 4x6 kitchen / desk / entry photos
