Hold–Find–Plan — all physical

Clinician activity materials. Not a medical device. Does not treat ADHD, concussion, or stroke.

Kit on the table

  • 9 picture cubes (or sticker dice) + folder occluder
  • Printed scene card (kitchen / desk / entry)
  • This pack: assignment card, wrap list, log
  • Phone timer only if you want a beep — the folder is the cover

Trial

  1. Set n cubes. Client names them.
  2. Cover with the folder. Wait the assigned seconds. No talking.
  3. Flip the scene. Find the items.
  4. Do only the assigned wrap.
  5. Log. Stop at 8 home trials.

Wrap list

  1. Find only
  2. Find in reverse
  3. Find all except the first
  4. Make one sentence using two held items
  5. Give a 2-step direction using two held items
  6. Which do you handle first, and why?
